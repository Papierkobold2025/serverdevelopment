# Netdata Integration

- Netdata is a program to monitor hardware health and status

## Decisions

- Netdata was decided as replacement for zabbix, as it is a more Plug-and-go solution and easier to configure alerts for my needs.

### Issues encountered

- Netdata parents do not accept network ranges, when I tried to apply a range 192.168.X.X/X the child nodes could not be mapped

### Runbook

- Installation of netdata (The same installation has to be done in Child and Parent nodes)
```bash
curl -Ss https://raw.githubusercontent.com/netdata/netdata/master/packaging/installer/kickstart.sh | sh
```
- The stream configuration file for netdata is not exposed automatically and has to me summoned into directory with the following command
```bash
./edit-config stream.conf
```
- Next in the parent node has to be generated an API Key
```bash
uuidgen
```
- Configuration file for parent node
```bash
[API-Token] # The generated API Token with uuidgen
    type = api
    enabled = yes
    allow from = 192.168.X.X 192.168.X.X # Child node IPs
    retention = 3600
    db = dbengine
    health enabled = auto
```
- Configuration file for child node
```bash
[stream]
    enabled = yes
    destination = 192.168.X.X:19999 # IP Address of parent node with port where netdata listens
    api key = API_Token # Secret API Token generated by the parent node
```
